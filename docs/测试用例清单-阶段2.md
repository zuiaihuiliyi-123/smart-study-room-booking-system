## 0. 执行约定

1. **时间基线**：所有与时间窗口相关的用例在 pytest 中冻结 `time_utils.now()` 为
   `2026-11-24 10:00`（Asia/Shanghai），保证边界可重复。接口用例用 `TestClient`，
   并发用例用文件型 SQLite + 独立 session + 线程（沿用 `tests/test_concurrency.py` 的做法）。
2. **断言三层**：HTTP 状态码 → 响应 `code`/关键字段 → 数据库终态（预约、槽位、违约、黑名单、消息、审计）。
3. **不修改业务代码**：阶段 3 若实际结果与预期不符，先记录复现证据，经确认后再修复。
4. **不写生产/共享库**：全部用例只使用测试库；不连接本机 MySQL。
5. **代号**：
   - `NOW` = 2026-11-24 10:00；`D0` = 11-24；`D1` = 11-25；`D7` = 12-01；`D8` = 12-02。
   - `R1`：启用中自习室，开放 08:00–22:00；`AR1`：R1 下的分区。
   - `E1..E10`：可用座位；`EFIX`：维修中；`EOFF`：停用。
   - `S1..S8`：正常学生，口令 `Ss123456`；`SLIMIT`：受限学生；`SOFF`：停用学生。
   - `ADM1/ADM2`：自习室管理员；`SYSA`：系统管理员。
   - `key(n)`：长度 ≥8 的幂等键，如 `qa-key-0001`。
6. **接口简写**：`POST /reservations` 即 `POST /api/v1/reservations`；其余同理。
